# Market header photography and flag artwork

The market header serves optimized WebP derivatives locally. CSS controls contrast, cropping and transparency for each theme.

- Bitcoin obverse cropped from *Gold Physical Bitcoins*, by Bits86, 2014. [Wikimedia Commons file and CC0 dedication](https://commons.wikimedia.org/wiki/File:Gold_Physical_Bitcoins.jpg)
- *Elon Musk Royal Society*, photograph by Debbie Rowe. Attribution: The Royal Society. This resized WebP derivative is available under the same [CC BY-SA 3.0 license](https://creativecommons.org/licenses/by-sa/3.0/). [Original source and file history](https://commons.wikimedia.org/wiki/File:Elon_Musk_Royal_Society_%28crop2%29.jpg)
- *Flag of the United States*, public domain. [Wikimedia Commons file and licensing](https://commons.wikimedia.org/wiki/File:Flag_of_the_United_States.svg)
- *Flag of the People's Republic of China*, public domain. [Wikimedia Commons file and licensing](https://commons.wikimedia.org/wiki/File:Flag_of_the_People%27s_Republic_of_China.svg)
- *Flag of South Korea*, public domain. [Wikimedia Commons file and licensing](https://commons.wikimedia.org/wiki/File:Flag_of_South_Korea.svg)
- Liang Wenfeng (梁文锋), DeepSeek founder. The China A-share header uses an original AI-assisted editorial illustration. The individual is identified at the right of the municipal news photograph in [Hangzhou's report on the premier's AI roundtable](https://www.ehangzhou.gov.cn/2025-01/22/c_292410.htm).

- The metallic shark in the share poster is original artwork generated for Bulls & Bears with ImageGen.
